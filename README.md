# 🎮 TIC TAC TOE GAME

A simple Tic Tac Toe game built using HTML, CSS & JavaScript  
👤 Human vs 🤖 Computer

## 🚀 FEATURES

- Human vs Computer mode
- Score tracking system
- Win detection (row, column, diagonal)
- Draw detection
- Simple AI opponent
- Restart / Reset option

## 🛠️ TECH STACK

- HTML
- CSS
- JavaScript (Vanilla)

## 🎮 HOW TO PLAY

1. Open index.html in browser
2. You play as ❌
3. Computer plays as ⭕
4. Click empty box to make move
5. First to make 3 in a row wins 🏆
6. Score updates automatically

## 🧠 GAME LOGIC

- Checks win conditions after every move
- Blocks same cell re-click
- Computer chooses random empty cell
- Game ends on win or draw
